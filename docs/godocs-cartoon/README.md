# Cartoon Style GoDocs style

Production assets for a history-only animated documentary channel, built with the Animate skill. Formats: 9:16 main, 16:9 second.

| File | Content |
|---|---|
| STYLE-BRIEF.md | The visual style spec, palette sets, characters, motion rules and thumbnail spec |
| ANIMATION-BRIEF.md | The Animate brief template, run order, fields per scene and sample rows |
| RESEARCH-PROMPT.md | The five-minute research prompt. One variable: [TOPIC] |

Run order: research prompt, then the system prompt, then the animation brief. The system prompt and the channel analysis are not in this repo.
